# Verified pages are indexed; samples are not

Programme URLs are an acquisition channel only after the row is checked against an employer page. `app/sitemap.ts` lists verified programmes. Sample pages stay reachable for the scorer and the harness, and they send `noindex`.

The operating cadence is a monthly pass of every `sourceUrl`, not a scraper. `npm run audit:windows` prints the checklist. Unknown fields stay empty. A 404 is a reason to cage the row, not to invent a window.
