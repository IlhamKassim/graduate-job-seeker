# Verified programmes are editorial, not scraped

A working product cannot show thirty invented windows on a public URL. The first slice is Malaysia-only records checked against employer pages on 15 September 2026. The slice later grew to ten, then eleven when RHB’s Management Associate Program was checked against the employer Workday posting. Anything we could not pin to a primary page stays a sample and is hidden until the student asks to see samples.

We do not scrape careers sites, call an LLM, or fill missing CGPA/stages with plausible numbers. If a page does not publish a field, the field is empty or the process list is only what the page named. Sample records remain in the repo so the scorer and calendar still have a wide set for testing.
