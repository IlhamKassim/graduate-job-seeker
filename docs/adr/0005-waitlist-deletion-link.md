# Waitlist deletion is a one-time link, not an operator inbox

PDPA access to deletion cannot wait on whoever reads GitHub. A student who left an address after a shortlist can open `/delete/`, type the same address, and receive a one-time link. Consume removes the waitlist row, unused magic links, and outbound mail for that address. Product events stay, without email or CGPA.

The request always answers `{ ok: true }`, so the page never confirms membership. A restore token cannot be spent as a deletion token: `langkah_magic_links.purpose` is `return` or `delete`.
